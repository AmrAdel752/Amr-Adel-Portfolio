# MemberDesk Pro — Marketing & Sales Website

**A Product Marketing Site with a Live Interactive Demo — for a Real Commercial Windows App**

Unlike the other concept sites in this portfolio, this is the **live marketing and sales website** for a real, shipped product: MemberDesk Pro, an offline-first membership-management desktop app. The site's job is to explain the product, prove it works via a real in-browser preview, and convert visitors into buyers.

---

## Overview

MemberDesk Pro (the desktop app) is an offline-first Windows application for local membership-based businesses — gyms, sports clubs, academies, training centers, clinics — to manage members, subscriptions, attendance, and payments without needing an internet connection. This website is the **commercial front door** for that product: it explains the problem it solves, shows the real product interface, lets visitors try a fully interactive browser-based preview of the app, and sells it through a real checkout flow.

- **Type:** Product marketing & e-commerce website (live commercial site, not a concept demo)
- **Status:** Live — checkout is a real payment integration; the in-browser product preview runs on seeded/fictional demo data only
- **Visual direction:** Dark navy hero sections paired with clean light content sections, blue accent

## Key Features

### Home
- Hero framing the core pitch: "Offline-first membership management for local businesses"
- Direct paths to buy, try the interactive demo, or view pricing

### Problem / Benefits
- "Stop running membership operations through scattered spreadsheets" — names the specific pain points it replaces (scattered records, missed renewal dates, slow attendance tracking, manual payment logging)
- "A practical desktop workspace for repeated front-desk work" — maps each pain point to a concrete benefit (track renewals, understand balances, print members quickly, record attendance faster)

### Product Screenshots
- Real interface screenshots of the Windows desktop app (Members List, Member Form, Dashboard) — captioned as using demo/sample data

### How It Works
- Three-step purchase-to-use process: Purchase MemberDesk Pro → Receive the Windows package → Install and operate locally

### Use Cases
- Grid of target business types: Gyms, Sports Clubs, Football Academies, Training Centers, Private Academies, Clinics, Coaching Spaces, and general local membership businesses

### Features
- Full functionality list with business framing: Member Management, Membership Plans, Subscriptions, Attendance, Payments, Reports, Roles/Personas, Login/Clock work, English/Arabic support, Light/Dark mode

### Pricing
- One-time digital product purchase, framed clearly ("exact commercial terms may vary")
- Three tiers: **Personal/Starter** (one local seat), **Business** (onboarding, branding, support), **Custom** (bespoke workflows and deployment)

### FAQ
- Direct, trust-building answers: is MemberDesk Pro free (no), how you receive it, whether the installer is public, whether the browser demo is the real product, internet requirements, supported OS, customization

### Checkout
- Real payment page (card or Google Pay), billing address, tax ID field, order summary — a genuine e-commerce checkout, not a mockup

### Live Interactive Demo
- **Choose a Demo Role** — visitors pick a persona (Administrator, Receptionist, Accountant) to preview the product from that role's perspective
- The chosen role loads a **fully interactive browser preview** of the actual desktop app UI — dashboard with live-feeling stats (members, active subscriptions, revenue, expiring subscriptions), sidebar navigation (Dashboard, Members, Plans, Subscriptions, Attendance, Payments, Reports, Settings), all clearly banner-labelled as using fictional/seeded demo data with no production backend
