# Finding Perfect

**A Minimal Fashion E-Commerce Concept — Static Demo**

A clean, editorial fashion e-commerce front end focused on effortless browsing: fast filtering, a quick-view/add-to-cart flow that never forces a page reload, and a fully fleshed-out support layer (contact, FAQ, store locator) that most portfolio e-commerce demos skip.

---

## Overview

Finding Perfect is a static fashion storefront demo covering the full customer journey from discovery to checkout intent — browsing, filtering, quick-viewing a product, adding it to a cart drawer, and reaching out through contact/FAQ — without any real backend, payment processing, or order fulfillment.

- **Type:** Front-end concept / portfolio project
- **Status:** Demo — cart, checkout, and form submissions are front-end only ("Checkout is not connected to a payment service")
- **Visual direction:** Minimal editorial layout, light background with purple accent

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Key Features

### Home
- Editorial hero ("Style that feels unmistakably yours") with category quick-filters and a promotional banner (e.g. seasonal discount)

### Shop
- Full product grid with a **Filters** sidebar: category, price range, size, colour
- **Quick Add** and **Quick View** on every product card
- Quick View modal shows description, price, size selection, and Add to Cart — without leaving the grid

### Cart Drawer
- Slide-out cart summarizing selected items, quantities, and subtotal
- "Proceed to Demo Checkout" call to action (clearly marked as non-functional demo)

### Catalogue
- Category-first browsing entry point ("Shop All"): Women, Men, Children, Footwear, Essentials
- Product-count badges per category

### About
- Brand story ("Designed around individuality", "A demo store concept with a real product mindset")
- Value props: Thoughtful Design, Everyday Comfort, Inclusive Style, Better Experiences
- Quick stats strip (demo pages, catalogue styles, core categories, front-end-only disclosure)

### Newsletter
- "Stay in the Loop" email capture section

### Contact
- Store contact hero ("Let's talk")
- Contact form (name, email, phone, subject, message)
- Location panel with placeholder map (labelled as a visual placeholder, no external API connected)

### FAQ
- Accordion covering common demo-specific questions (Is this a real store? Can I place a real order? Does the form send email? Are payments connected?)

### Footer
- Site-wide navigation, shop links, support links, and contact details
