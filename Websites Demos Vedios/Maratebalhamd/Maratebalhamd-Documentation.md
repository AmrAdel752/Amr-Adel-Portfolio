# Maratebalhamd — Al-Hamd Mattress Showroom

**An Authorized Habitat, Janssen & Sleep High Dealer Platform — .NET Web API & Angular**

A genuine client business: a live e-commerce-style showroom site for an authorized mattress dealer in Faisal, Giza, currently deployed at **maratebalhamd.com**.

---

## Overview

Al-Hamd Mattress Showroom is an authorized dealer for three mattress brands (Habitat, Janssen, Sleep High) and needed a site that could do what a physical showroom visit does: let a customer compare brands, understand mattress types, find their size, and get a real price from the owner — all funneled through WhatsApp.

- **Type:** Real client project — live, in-production business platform
- **Status:** Live and deployed (maratebalhamd.com)
- **Visual direction:** Warm, trustworthy green-and-cream palette with real showroom photography

## Tech Stack

- .NET Core Web API (backend)
- Angular (frontend)
- SQL Server (database)
- WhatsApp deep-link integration for price inquiries

## Key Features

### Brand Catalog
- Three authorized brands (Habitat, Janssen, Sleep High) each with its own showcase section and construction details (spring type, memory foam, latex layer, toppers, waterproofing)

### Product Listings
- Individual mattress models per brand (e.g. Habitat Contract, Habitat Breeze, Habitat Super Heaven), each with height/spec details and a direct "Ask for Price" WhatsApp action that includes the model name

### Mattress Finder Quiz
- A 3-question guided tool (sleep position, back pain, firmness preference) that recommends a mattress type and can be sent straight to the owner on WhatsApp

### Mattress Type Guide
- Side-by-side comparison of connected springs (Bonnell), pocket springs, medical/orthopedic mattresses, and pillow-top/memory foam — stability, motion isolation, and softness rated for each

### Size Guide
- Full Egyptian mattress size reference (90×195 up to 180×200) with a one-tap "ask about this size" action

### Real Showroom Gallery
- Genuine photos from inside the physical showroom (mattresses, cross-section layers, pillows & linens), filterable by category

### FAQ & Location
- Common buyer questions (pricing, warranty — 10-year factory warranty, delivery, installment/down-payment terms) plus address, working hours, and a direct line to the owner, Ahmed Saad
