# El Sayed Hassan Auto

**A Full-Stack Nissan Service Center Platform with Admin Dashboard — .NET Web API & Angular**

Unlike the concept projects elsewhere in this portfolio, this is a genuine client business: a fully built and deployed platform for a real Nissan-specialist service center in Giza, currently live at **elsayedhassanauto.com**.

---

## Overview

El Sayed Hassan Auto is a Nissan-only maintenance center (Faisal / Giza) that needed a complete digital front door: a bilingual (Arabic/English) marketing site that converts visitors into WhatsApp bookings, plus a private admin dashboard so the business owner can manage services, offers, spare parts, and incoming bookings without touching code.

- **Type:** Real client project — live, in-production business platform
- **Status:** Live and deployed (elsayedhassanauto.com)
- **Visual direction:** High-contrast red-and-black automotive branding with a bilingual AR/EN toggle

## Tech Stack

- .NET Core Web API (backend)
- Angular (frontend)
- SQL Server (database)
- WhatsApp deep-link integration for bookings

## Key Features

### Home
- Hero section ("عربيتك النيسان في إيد أمينة") with live stats (years of experience, specialization %, days/hours open)
- Direct WhatsApp "Book Now" call-to-action throughout

### Services Catalog
- Nine dedicated services (Mechanics, Periodic Maintenance, Suspension, A/C, Spare Parts, Oils, Tire Alignment, Washing, Body & Paint), each with its own detail panel

### Interactive Car Diagram
- Clickable hotspots on a car illustration (Engine & Transmission, Fluids, A/C, Suspension & Brakes, Periodic Maintenance, Spare Parts) linking straight to the relevant service

### Limited-Time Offers
- Live countdown-timer discount campaigns (e.g. a 35% maintenance package offer) to drive urgency

### Nissan Model Coverage
- Full model lineup supported (Sunny, Sentra, Qashqai, X-Trail, Juke, Tiida, Patrol, Kicks, Magnite, Navara, Pathfinder, Altima, Maxima, Murano)

### Spare Parts & Oils Catalog
- Genuine/agency-sourced parts and oils listed by compatible model, each with a "Ask for Price" WhatsApp action

### WhatsApp Booking Flow
- Multi-step booking form (car model → service → preferred day/time → notes) that generates a pre-filled WhatsApp message — no typing required from the customer

### Customer Reviews
- Real dated customer testimonials per service type (maintenance, A/C, suspension, etc.)

### Admin Dashboard
- Private back-office for the business owner to manage services, time-limited offers, spare-parts catalog, and incoming bookings — the public site and the dashboard share the same .NET Web API

### Location & Contact
- Address, primary/secondary phone numbers, live "open now / closed" working-hours indicator, and an embedded map link
