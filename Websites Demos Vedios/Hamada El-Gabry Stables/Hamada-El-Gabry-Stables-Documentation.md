# Hamada El-Gabry Stables

**A Horse Riding & Desert Safari Booking Platform at the Giza Pyramids — .NET Web API & Angular**

A genuine client business: a live tourism booking platform for a long-established horse stable in Nazlet El-Semman, right next to the Giza Pyramids, rated 4.9/5 from 2,600+ Google reviews.

---

## Overview

Hamada El-Gabry Stables needed a booking site that could convert tourists and locals browsing online straight into confirmed WhatsApp reservations — across a wide menu of experiences (horse riding, camel riding, carriage rides, beach buggies, desert safaris, horse shows, and riding lessons) with live pricing and time-of-day guidance (sunrise, sunset, night rides).

- **Type:** Real client project — live, in-production tourism business
- **Status:** Live and deployed, bilingual Arabic/English
- **Visual direction:** Cinematic desert/pyramid photography with warm gold accents

## Tech Stack

- .NET Core Web API (backend)
- Angular (frontend)
- SQL Server (database)
- WhatsApp deep-link integration with an auto-filled booking message

## Key Features

### Home
- Hero video/photo of horseback riding at the Pyramids with a live Google rating badge (4.9 from 2,600+ reviews) and an "open 24 hours" indicator

### Services Catalog
- Twelve bookable services: Pyramid horse riding, Arabian horse riding, beach buggy rental, camel riding, carriage (karetta) riding, desert safaris, dancing-horse shows, horse tabkish shows, desert BBQ nights, birthdays/events, riding lessons, and horse buying/selling — each with live per-hour pricing

### Signature Journeys
- Curated time-slot experiences (Sunrise Ride, Sunset Ride, Night Ride, Desert Safari) each with a defined time window and description

### Trip Timeline
- A 5-step visual walkthrough of what an actual booked trip looks like, from stable welcome to the panoramic photo stop to safe return

### Package Builder
- Pre-built packages (Pyramid Tour, Sunrise/Sunset Package, Safari Adventure, Family Package) with duration options and an "ask for price on WhatsApp" flow

### Trip Finder Quiz
- A short multi-question tool that recommends the right experience based on the visitor's riding experience level

### WhatsApp Booking Form
- A detailed form (service, date, time slot, duration, party size, nationality, notes) that assembles a complete, pre-filled WhatsApp booking message — multiple services can be selected at once

### Social Proof
- Real, attributed Google review testimonials and a live-updating 4.9★ rating summary

### FAQ & Location
- Pricing transparency (e.g. riding at 400 EGP/hour, buggy at 600 EGP/hour), what's included, and exact location details (Nazlet El-Semman, Giza) with a map link
