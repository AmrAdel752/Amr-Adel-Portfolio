# Hamada Ramadan — Nasr City Painter & Finishing

**A Lead-Generation Landing Page for an Interior Finishing Contractor — .NET Web API & Angular**

A genuine client business: a live lead-generation site for an interior painting and finishing contractor in Nasr City, Cairo.

---

## Overview

Hamada Ramadan needed a way to turn his real finishing work (painting, parquet polishing, wall putty, ceiling decor) into booked site inspections, without relying only on word of mouth. The site is built around one goal: get a visitor to send an inspection request over WhatsApp after seeing real, convincing proof of work.

- **Type:** Real client project — live lead-generation platform
- **Status:** Live and deployed
- **Visual direction:** Warm, residential palette built around real apartment photography and video

## Tech Stack

- .NET Core Web API (backend)
- Angular (frontend)
- SQL Server (database)
- WhatsApp deep-link integration for inspection requests
- YouTube embed integration for video proof-of-work

## Key Features

### Services
- Six core services (Full Apartment Finishing, Modern Paint, Parquet Polishing, Wall Putty & Sanding, Ceiling Decor & Lighting, Wall Panels & Decor), each with its own inspection-request action

### Real Work Photo Gallery
- Genuine, lightbox-enabled photo gallery from completed apartments, labeled by room and finish type (LED ceiling + parquet, herringbone parquet, finished bathroom, hallway lighting, etc.)

### YouTube Video Showcase
- Embedded videos pulled from the contractor's own YouTube channel, giving prospects a walkthrough of a delivered apartment

### Before/After Comparison
- Side-by-side video comparison of the same apartment before work started and after handover — tangible proof of transformation

### Guided Process
- Four-step explainer (Contact → Site Inspection → Fixed Quote → Execution & Delivery) that sets clear expectations before a customer commits

### WhatsApp Inspection Request Form
- Short lead form (name, area, type of work) that packages the request straight into a WhatsApp message to the contractor — even while he's on a job, the lead is captured

### FAQ
- Common pre-booking questions (how inspection works, coverage area, parquet polishing availability, turnaround time, who supplies materials)
